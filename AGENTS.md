# Project instructions

При работе с frontend сначала прочитайте [соглашение frontend](frontend/AGENTS.md).
Оно также применяется к изменениям документации и конфигурации, затрагивающим frontend.

## Тесты .NET

Для каждого тестового метода добавляйте XML-комментарий на русском языке:
что проверяется и какой результат ожидается. Для параметризованных тестов
поясняйте смысл входных параметров. В xUnit также задавайте понятный русский
`DisplayName` у `[Fact]` и `[Theory]`, чтобы сценарий был читаем в Test Explorer.
Правило применяется ко всем новым и изменяемым тестам .NET.
