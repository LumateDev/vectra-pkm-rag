# Frontend

Соглашение для всех разработчиков и агентов: [frontend/AGENTS.md](../../frontend/AGENTS.md).

Исходный код находится в `frontend/`. Стек: Vue 3, TypeScript, Quasar CLI с Vite.

Реализованы стартовые страницы `/login` и `/register`, адаптивная оболочка,
проверка email, длины и подтверждения пароля, переключение видимости пароля.
Подключение к backend пока не реализовано.

Запуск, команды проверки и структура: [frontend/README.md](../../frontend/README.md).
